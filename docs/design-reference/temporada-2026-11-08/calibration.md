## Coordinate convention recorded before UI edits

Adopt a **393 × 852 logical** comparison viewport with 2 source pixels per dp. This is an explicit calibration assumption, supported by the roughly 60px page headings (30sp), 28px body (14sp) and 108px buttons (54dp); it is not an assertion that source pixels inherently encode dp. Native Roboto metrics/weights can differ from raster export fonts. Reference text bands were measured from near-black pixel runs, not guessed from the contact sheet.

Common targets: horizontal margin 25dp (50px); page title 30sp/36dp line; body 14sp/22dp; compact labels 11sp/16dp; wordmark 20sp black bold; field text 18sp, field height 56dp; action text 16sp, height 54dp; radius 12dp on emphasized panels and 10dp on controls. Native 48dp touch regions enclose compact header labels/icons. Secondary functional text is darkened where the illustrative color fails contrast.

Primary/auth header text ink starts near y=74dp; title ink near y=142dp (Home/My Job/picker). With Android top inset 24dp, the header region begins at 60dp and is 48dp tall, followed by 24dp to the title block. Secondary back/context headers occupy the same 60–108dp region; title block starts at 132dp. Sign-in intentionally adds 64dp after the header, placing two-line 36sp/42dp title ink near y=208dp. References have fake status chrome; actual system bars are retained and recorded, not fabricated or cropped.
