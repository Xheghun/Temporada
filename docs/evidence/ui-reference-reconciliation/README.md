## Discrepancy register

- **Resolved structural differences:** oversized/general headers, duplicate secondary chrome, generic card framing, absent numbered rows, full-width ordinary document buttons, missing prominent sent summary, missing employer panel/field labels, missing camera placeholder hierarchy, filled navigation pills, OTP combined phone explanation and unframed picker rows.
- **Data adaptations retained:** full selected display name and neutral greeting; real alphabetical catalog order; DS-160 rather than illustrative Passport is the delivered item; actual v2 summary/reference/dates; two authorized workers rather than three. Offline capability panels describe a supported behavior even while online. The Documents check cue means delivered/reviewable; its adjacent explicit status does not claim approval.
- **Accessibility adaptations retained:** 24dp margins rather than 25dp (1dp); 48dp hit areas around compact headers; contrast-safe secondary/input colors; minimum 54dp ordinary actions; native Roboto glyph metrics produce the quantified text offsets above. Large text can require scrolling and the capture placeholder shrinks to 180dp on short screens, keeping actions practical.
- **System adaptations retained:** actual status/navigation bars and Expo development overlay. No screenshot crop hides them. The contact-sheet artwork and fake device chrome are not reproduced.
- **Functional additions retained below reference content:** refresh, sign-out, alternate-number and contextual fallback controls where supported. Reference fidelity does not remove recovery paths.
- **Remaining exact-geometry limit:** native raster/font environment is not supplied with the concepts. The eight structural comparisons have been inspected individually, but pixel-perfect equivalence is not claimed. No unresolved missing reference section or inert control was accepted on palette similarity alone.
